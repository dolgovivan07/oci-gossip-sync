**OCI Gossip Sync** — это распределенный сервис для оптимизации развертывания контейнеров в кластерах. Он ускоряет загрузку OCI-совместимых образов за счёт peer-to-peer обмена слоями между узлами с использованием gossip-протокола, минимизируя нагрузку на центральный registry.

Проект разработан в рамках практического задания от **VK Education**.

## 💡 Архитектура проекта

Проект разделен на две логические части, демонстрирующие микросервисный подход и уместность выбора технологий под конкретные задачи:

1. **P2P Agent (Go):** Легковесный демон, работающий на каждом узле кластера. Отвечает за парсинг OCI-манифестов, поддержание P2P-сети (gossip) и потоковую передачу tar-архивов (слоев образа) соседним узлам.
2. **Control Plane (Java / Spring Boot):** Центральная панель управления. Собирает телеметрию с узлов, логирует статусы скачивания, рассчитывает метрики (hit rate, сэкономленный трафик) и хранит историю в PostgreSQL.

## ✨ Ключевые возможности

- **P2P-передача слоев:** Узлы скачивают недостающие слои контейнера напрямую друг у друга в обход Docker Hub.
- **Gossip-протокол:** Быстрое обнаружение соседей в локальной сети и синхронизация списков доступных слоев (на базе HashiCorp `memberlist`).
- **Соответствие OCI:** Работа с Image Manifest V2 и проверка целостности файлов по SHA256-дайджестам.
- **Интеграция с Container Engines:** Поддержка работы через локальный прокси для прозрачной интеграции с Docker и Podman.
- **Аналитика:** Сбор подробных метрик распределенной системы в реальном времени.
